1. (선택) 남은 앱 확인: 움직임 끄기(17번), 프로젝트별 오늘(18번), 90% 알림이 뜨는 순간, 네트워크 끊김, git 아닌 폴더, 큰 저장소 — `docs/test-plan.md` 4절
