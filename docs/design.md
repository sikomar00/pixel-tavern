# 디자인

작성일 2026-11-05. 기존 디자인의 정체성을 유지한 채 정리한 문서입니다. 바꾸자는 제안은 `implementation-plan.md`에 있습니다.

## 정체성

아늑한 판타지 + 레트로·픽셀·로파이·비디오게임. 장면은 10개이고, 이름은 기능이 아니라 분위기만 말한다.

| 장면 | 분위기 | 기본 방송(`http`) |
|---|---|---|
| 비 오는 밤 다락방 | 아늑 | REYFM 로파이 |
| 7080 다방 | 아늑 | 올드팝카페 |
| 8비트 던전 | 모험 | Kaaos 칩튠 라디오 |
| 네온 펑크 성 | 모험 | Nightride FM 신스웨이브 |
| 재즈 바 | 아늑 | Radio Swiss Jazz |
| 숲속 캠프파이어 | 아늑 | Groove Salad |
| 마법 서재 | 아늑 | Illinois Street Lounge |
| 오락실 | 모험 | VGM Radio |
| 80년대 드라이브 | 모험 | Underground 80s |
| 우주 정거장 | 모험 | Nightride Datawave |

방송은 패널의 음악 구역에서 장면마다 따로 고를 수 있다(16곳, 분위기별로 묶어 둠: 잔잔 · 7080 · 게임 · 신스웨이브). 방송은 `▸ 방송 바꾸기`를 눌러 펼친 뒤 묶음 버튼(★ 즐겨찾기 · 잔잔 · 7080 · 게임 · 신스)과 그 묶음의 방송 버튼에서 고르고(평소에는 접혀 있다), 지금 방송은 진한 버튼이며 즐겨찾기한 방송은 이름 앞에 `★`가 붙는다.

새 장면 6개도 같은 규칙(85칸 폭·4배 확대·움직임은 깜박임·프레임·이동만)으로 그렸고, **게이지는 장면마다 다른 물건**이다: 재즈 바 = 칵테일 잔이 차오름, 숲속 캠프파이어 = 장작더미가 쌓임, 마법 서재 = 모래시계, 오락실 = LED 막대(초록 → 노랑 → 빨강), 80년대 드라이브 = 계기판 바늘, 우주 정거장 = 산소 튜브. 게이지 글자는 `컨텍스트 n%`로 모두 같다.

그림은 픽셀 격자를 4배로 키운 SVG이고(계획 기준 8~12색, 2~4프레임의 끊기는 움직임. 패널의 `움직임 켬/끔` 버튼으로 멈출 수 있고 정지 그림은 첫 프레임이다), 패널에서는 폭 296px로 잘라 보인다 **[시험]**. 글자는 한글 고딕. **게이지에는 비유 이름을 쓰지 않는다**(촛불·찻잔·마나 등 제거, 시험으로 보호): 컨텍스트 · 5시간 · 주간.

## 정보 위계

- **배너(항상)**: 장면 그림 + 사용량 요약 + 버튼 ▶ ▤ ⟳ ✕. 숨겨도 사용량은 한 줄로 남는다.
- **패널(자세히)**: 위에서 아래로 장면 고르기(`◀ 이름 n/N ▶`, 아래 줄에 그림 접기·움직임 켬/끔·`?`) → 그림 → 음악(세 줄: 방송 이름·상태 / 재생·음량 / `방송 바꾸기`·`☆ 즐겨찾기`. `방송 바꾸기`를 누르면 묶음 버튼과 방송 버튼이 펼쳐짐) → 빠른 실행 → 할 일(칸·항목 줄) → 사용량 → 작업 현황 → 파일. 구역(음악·빠른 실행·할 일·사용량·작업 현황·만진 파일)은 모두 같은 카드(밝은 배경 + 왼쪽 강조 막대)이고 카드 사이에 바탕색 틈이 있다. 구역마다 ▾로 접고 펼 수 있고, 접으면 한 줄 요약이 남는다. 커밋 로그·바뀐 파일 목록·프로젝트별 오늘(오늘 두 프로젝트 이상에서 일했을 때만 나온다)은 기본으로 접혀 있다.
- **도움말**: `?`가 5곳(장면·음악·빠른 실행·사용량·작업 현황)에 있고, 누르면 패널 안에서 펼쳐진다.
- **처음 한 번만** 안내 문구를 보인다.

## 지키는 규칙

| 규칙 | 이유 |
|---|---|
| 버튼 이름은 글자 하나(▶ ■ ⟳ ✕ ▤)이거나 패널 안의 짧은 낱말 | 이름과 자식 글자가 겹쳐 그려지는 문제가 있었음(엔진은 이름이 있으면 자식을 그리지 않음) |
| 정지 그림은 따로 그리지 않고 실행할 때 만든다 | 그림 두 벌을 관리하지 않으려고. 움직임이 모두 같은 모양(요소 안의 `<animate>` 하나)이라 가능하며, 그림을 새로 만들 때도 이 모양을 지켜야 한다(`tests/still.test.tsx`가 4장면 전부에서 확인) |
| 방송 목록의 서버는 사용자가 승인한 곳뿐이고 주소는 모두 `http` | 새 외부 서버로의 접속이 몰래 늘지 않게. 방송을 더하려면 이름·서버·실제 재생 결과를 보여 주고 승인받은 뒤 목록과 시험의 허용 목록에 함께 적는다 |
| 스크롤해서 고르는 목록(드롭다운)은 쓰지 않는다 | 항목이 늘어도 한 번 눌러서 고르게(사용자 요청). 장면은 `◀ ▶`, 방송은 묶음 버튼 + 방송 버튼으로 한 화면에 버튼이 10개 안팎만 보이게 한다 |
| 구역은 모두 같은 카드(밝은 배경 + 왼쪽 강조 막대)이고 카드 사이에 바탕이 비친다 | 어느 구역이 어디서 끝나는지 한눈에 보이게(사용자 지적). 예전에는 구역마다 배경이 제각각(어떤 건 카드, 어떤 건 바탕)이라 줄무늬처럼 보였다. 카드를 더 밝히지 않은 것은 강조색 글자 대비 4.5를 지킬 수 있는 한계(7%)라서이고, 대신 막대와 틈으로 구분한다. 막대가 안 보여도 카드 배경과 틈은 남는다 |
| 음악은 평소 세 줄이고 방송 고르기는 접어 둔다 | 사용자 지적(번잡함). 버튼이 열댓 개 늘어서 있던 것을 자주 쓰는 것(재생·음량·즐겨찾기)만 남기고, 방송은 바꿀 때만 펼친다. 펼침은 저장하지 않아 열 때마다 조용하다 |
| 할 일 목록은 항목 · 체크박스(완료) · 우선 표시(★)뿐이다 | 구글 태스크처럼 간단히(사용자 요청). 기한·메모·하위 항목은 두지 않는다. 요청 범위 밖으로 `완료한 것 지우기` 한 줄만 더했다 |
| 경고색은 `#ff7a7a` | 카드 배경에서 대비가 낮아 밝게 고침. 시험이 대비를 계산(카드 위, 장면 바탕 위 모두) |
| 바뀐 파일은 기호 하나로 종류를 나타낸다(+ 새 · ~ 수정 · - 삭제 · > 이름 변경 · ! 충돌) | 색을 못 보는 사람도 구분. 삭제·충돌만 경고색을 더하고 충돌이 맨 위. 뜻은 `?`에도 있다 |
| 빠른 실행 버튼 아래에 진행 상태 한 줄(`◌` 대기 · `●` 진행 중 · `✓` 끝 · `○` 중단 · `✕` 실패) | 눌렀는데 아무 반응이 없어 보이지 않게. 음악 상태와 같은 기호 말을 쓰고, 실패만 경고색. 끝난 표시는 60초 뒤 사라진다 |
| 간격은 엔진의 단계(`xs…xl`) | 데스크톱에서 6/8/12/16/24px로 실측. 숫자로 직접 쓰면 글자 칸으로 해석됨 |
| 크기는 실측값 기준(`tools/measured.json`) | 이전에 틀린 가정(268px·74%)을 실측으로 바로잡음 |
| 그림은 선언한 px 그대로 그려진다 | 폭에 따라 사용량 링 폭을 계산(`usageWidthFor`) |
| 사용량 링은 20칸(5%), 0%보다 크면 최소 1칸, 100% 미만이면 가득 차지 않음 | 숫자와 그림이 어긋나 보이지 않게 |
| 경고(≥90%)와 재경고 조건(<80%) | 같은 구간에서 알림이 반복되지 않게 |

## 접근성

- 대비: 경고색·카드 글자 대비를 시험이 계산한다 **[시험]**.
- 그림 대체 글: 장면 이름과 문구가 `alt`에 있다 **[시험]**.
- 키보드 이동·포커스 표시: 엔진이 담당, 모드에서 확인하지 못함 **[미검증]**.
- 마우스를 올려야만 보이는 `?` 설명은 클릭으로도 펼쳐진다(마우스에 의존하지 않음).
- 움직임은 `움직임 끔` 버튼으로 멈출 수 있고(첫 프레임의 정지 그림, 배너와 패널 모두, 설정은 기억) 4장면 전부에서 움직임이 남지 않음을 시험이 확인한다 **[시험]**. 운영체제의 "동작 줄이기" 설정은 모드가 읽을 수 없어 자동으로 따르지는 않는다. 실제 앱에서의 모습은 **[미검증]**(R-26).
