## 커밋 전(2026-11-05, 오늘 통계 동시 갱신 정확성 — F-09)

- **fix(stats)**: 오늘 통계가 여러 채팅이 겹치면 한 번이 사라지던 문제를 고침. 옛 방식(모두가 `today` 키 하나를 읽고-고치고-쓰고 합칠 때 `max`)은 10에서 두 채팅이 1씩 늘리면 11이 됐다(시험으로 재현: 기대 12·실제 11). 채팅마다 자기 칸(`today:<날짜>:<칸 이름>`)에 **누적값**만 쓰고 합계는 칸들의 합으로 만든다. `max`를 `+`로 바꾸는 단순 수정은 중복 집계 위험이라 택하지 않았다.
- 쓰기를 한 줄로 세워 완료 순서가 뒤바뀌어도 마지막이 최신, 1분마다 내 칸을 다시 써서 사라진 쓰기를 바로잡음(저장소 파일 자체의 겹쳐 쓰기도 자가 치유), 지난 날 칸과 옛 합계 키 정리, 옛 합계 키는 읽기 전용 칸으로 호환.
- **privacy**: 수정 파일을 경로 대신 **지문(FNV-1a 8자리)**으로 저장(저장소가 작아지고 절대 경로를 남기지 않음). 실제 저장 파일에서 `today` 키 하나가 17.5KB였다.
- **refactor**: 통계 코드를 `state.ts`에서 `stats.ts`로 옮김(`state.ts` 314 → 255줄). `mergeToday`는 없앰(최댓값 규칙이 문제의 원인).
