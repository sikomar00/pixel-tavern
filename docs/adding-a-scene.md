# 새 장면 추가 절차

장면은 **저장소에 함께 올리는 일반 장면**으로 더합니다(사용자 선택: 비공개 장면은 따로 불러오는 장치가 필요해 훨씬 큰 작업이라 하지 않음).
가장 쉬운 방법은 말로 설명하는 것입니다: "이런 장면을 그려 줘"라고 하면 Claude가 아래 순서를 한 번에 합니다. 사람이 직접 하려면 같은 순서로 따라 하면 됩니다.
참고 예: `tools/scenes/rooftop.py`(가장 최근, 꽃 화단 게이지), `tools/scenes/camp.py`(장작 게이지).

## 1. 정할 것(한 줄씩)

| 항목 | 예(옥상 정원의 새벽) | 규칙 |
|---|---|---|
| 이름 | `옥상 정원의 새벽` | 다른 장면과 겹치지 않는다. 기능이 아니라 분위기만 말한다 |
| 모드 | 아늑 | 아늑 또는 모험 |
| 모토 | `물 한 모금, 코드 한 줄` | 다른 장면과 겹치지 않는다 |
| 게이지 물건 | 화단에 꽃이 한 송이씩 핌 | 컨텍스트 사용률 0~100%를 **21단계**(5%씩)로 보이는 물건. 이름은 쓰지 않고 `컨텍스트 n%` 글자만 쓴다 |
| 색 넷 | 바탕 `#1c1830`, 강조 `#ff9ec2`, 보조 `#ffd9a0`, 흐린 글자 `#c5b8dc` | 바탕과 강조·흐린 글자의 대비가 4.5 이상(시험이 계산). 바탕색은 다른 장면과 겹치지 않는다 |
| 기본 방송 | Fluid (SomaFM) | **장면마다 달라야 한다**(시험). 방송 16곳 중 지금 11곳이 쓰이고, 남은 곳은 `seventies`·`7soul`·`paralax`·`chillsynth`·`darksynth`다. 장면이 17개를 넘으면 이 규칙을 바꿔야 한다 |

## 2. 만들 것

1. **장면 파일** `tools/scenes/<id>.py`: 85×96 칸 캔버스에 그린다(패널은 위의 74줄만 보인다). `build()`가 `base`·`scene`·`gauges`(21개)·`labelSvg`·`labelName`·`strip`을 돌려준다. 지킬 것:
   - 움직임은 `blink`(깜박임)·`frames`(프레임)·`drift`(이동)와, 요소 하나 안에 `<animate>` 하나만 든 모양(불빛 `<ellipse>` 등)만 쓴다. 그래야 `효과` 버튼의 약하게·끔이 동작한다(시험이 그림 전부를 확인).
   - 마지막 층은 `MARKER`다: 그 자리에 게이지와 글자가 끼워진다. 밝기 덮개도 그 앞에 들어간다.
   - 게이지 21단계는 같은 상자 안에서 바뀌어야 한다(터미널 그림이 상자 크기를 단계에서 구한다).
   - 색은 한 장면에 89가지 이하(터미널 칸 그림의 기호 수). 합친 그림 한 장은 128KB 이하(도구가 검사).
   - 엠블럼(배너 왼쪽 12×10 칸 그림)과 배너 띠 불빛도 `build()`에서 만든다.
2. **등록** 여섯 곳(빠뜨리면 타입 검사나 시험이 알려 준다):
   - `tools/gen_art.py`의 `SCENES` 목록
   - `hooks/art/index.ts`와 `hooks/art/cells/index.ts`(불러오기 한 줄과 목록 한 곳씩)
   - `types/index.d.ts`의 `SceneId`
   - `hooks/scenes.ts`: `SCENES` 항목(이름·모토·색 넷·기본 방송)과 `MODES`의 장면 순서
   - `tools/tree_dump.scenario.tsx`의 장면 종류(미리보기 도구)
3. **시험의 개수**: 장면 수를 세는 시험을 고친다(`tests/data.test.tsx`, `tests/function.test.tsx`의 장면 수·모드별 개수·겹침 검사, `tests/terminal.test.tsx`의 제목). 규칙의 뜻은 그대로 두고 개수만 바꾼다.

## 3. 만든 뒤 확인

1. `python tools/gen_art.py`: 그림 파일(`hooks/art/<id>.ts`, `hooks/art/cells/<id>.ts`)이 만들어지고 한 장 크기가 나온다. **다른 장면의 그림 파일이 바뀌면 안 된다**(`git status`로 확인).
2. 눈으로 확인: `tools/preview/index.html`을 브라우저로 보거나 게이지 0·30·63·100%를 늘어놓은 그림을 본다. 게이지 글자가 그림 위에서 읽히는지, 꽃·장작 같은 게이지 물건이 단계마다 늘어나는지 본다.
3. `npm run typecheck` → `claude plugin validate .` → 시험(파일별 순차 실행).
4. 터미널 그림은 `python tools/render_term.py`로 근사해서 본다.
5. 문서: README 장면 목록, `docs/architecture.md`, `docs/changelog.md`, `docs/review/feature-matrix.md`, 시험 계획의 사람 확인 항목(실제 앱에서 보기).
6. **커밋·푸시는 사용자가 승인한 뒤에만** 한다.

## 한계

- 그림은 사람이 취향으로 봐야 한다: 이 절차는 틀이 맞는지(시험)까지만 확인하고, 마음에 드는지는 사용자가 정한다. 마음에 안 들면 장면 파일의 색·모양을 말로 고쳐 달라고 하면 다시 만든다.
- 비공개(내 컴퓨터에만 두는) 장면은 지원하지 않는다.
