# 성능 측정 (2026-11-09)

앱 밖에서 잴 수 있는 것만 쟀습니다. **엔진이 SVG 그림과 애니메이션을 실제로 그리는 시간은 못 쟀습니다**(앱에서 작업 관리자로 확인해야 하며 R-18에 남겨 둡니다).
측정할 때 컴퓨터는 다른 앱 때문에 CPU 약 45%가 이미 쓰이고 있었습니다. 숫자는 대략적인 크기로 보세요.

## 방법

| 무엇 | 어떻게 |
|---|---|
| 그리기 함수·모듈 불러오기 | `node tools/bench_render.cjs`: 모드의 `hooks`를 TypeScript로 임시 폴더에 옮겨 적고 Node에서 함수를 직접 부름(워밍업 30번 뒤 300번의 중앙값·95%·최대). 엔진은 없음 |
| 화면 다시 그리기 횟수 | 임시 복사본의 `register.tsx` 그리기 훅에만 카운터를 넣고(저장소 파일은 그대로) 시험 도구로 시나리오를 돌림. **시험 도구가 다시 그리는 방식 기준**이라 실제 앱과 다를 수 있음 |
| git | 훅과 같은 인자(`--no-optional-locks -c core.fsmonitor=false status --porcelain=v1 -z -b`, `log -3`)를 저장소 크기별로 7번씩 실행(프로세스 시작 포함, 벽시계) |
| 곡 제목 읽기 | 실제 스크립트(`TITLE_SCRIPT`)를 실제 방송(REYFM)에 5번 실행하고 PowerShell 프로세스의 CPU 시간(`TotalProcessorTime`)과 벽시계 시간을 잼. 빈 PowerShell(시작만)과 비교 |

## 결정

- **곡 제목 읽기 간격 30초 → 60초**(사용자 선택): 평균 약 1.8%. 상주 PowerShell로 바꾸면 약 1.3%까지 내려가지만 프로세스 정리·오류 처리가 복잡해져 하지 않았다(필요하면 다시 검토).
- 그 밖의 항목(그리기 함수 캐시, git 호출 줄이기, 모듈 늦게 불러오기)은 값이 작아서 하지 않았다. 터미널 장면 그림은 (장면, 게이지 단계, 배율, 밝기)로 캐시하면 다시 그릴 때 3~8ms를 아끼지만 다시 그리기가 드물다.
- 재생기 자체는 예전 측정(`latest-commit-review.md`) 그대로 한 코어의 약 9%, 메모리 137MB다.

## 재생기 비교 — https 방송 조사(2026-11-09, R-13)

새 프로그램은 설치하지 않았다(`mpv`·`ffplay`·`ffmpeg`·`vlc`는 이 컴퓨터에 없다). Windows에 이미 있는 WinRT 재생기(`Windows.Media.Playback.MediaPlayer`)를 `tools/winrt_probe.ps1`로 음량 0에서 재생해 봤다. 모드가 쓰는 WPF 재생기의 값은 `python tools/player_check.py normal`(실제 재생기 스크립트)에서 가져왔다. **방송 하나씩만 본 값이고, 모드의 재생기 스크립트는 재연결·음량·부모 감시도 하므로 같은 조건의 비교는 아니다.**

| 재생기 | 방송 | 재생 시작 | CPU(30초 동안) | 메모리 |
|---|---|---|---|---|
| WPF(지금) | http(REYFM) | 6.3초 | 약 0.6초/10초(한 코어의 약 6%, 예전 측정은 9%) | 138MB |
| WPF(지금) | https | 25초 안에 재생 안 됨(예전 측정, `latest-commit-review.md`) | — | — |
| WinRT | https(SomaFM) | 1.8~2.8초 | 0.95초(약 3%) | 115MB |
| WinRT | http(REYFM) | 3.3~6.5초 | 1.00초(약 3%) | 115MB |

해석: WinRT 재생기가 https를 재생하고 CPU·메모리도 적다. 재생기를 바꾸면 https 방송을 쓸 수 있고 부담도 줄 것으로 보이지만, 재생기 스크립트(재연결 기다림·정지 신호·음량·부모 감시)를 옮겨야 하고 `player_check.py quick`·`dead`로 다시 확인해야 한다. 곡 제목도 WinRT가 방송의 제목을 알려 주는지 알아보면 곡 제목 읽기(평균 약 1.8%)를 없앨 수 있을지 모른다(확인하지 않음).

- 실제 앱이 화면을 다시 그리는 횟수(위 횟수는 시험 도구 기준).
